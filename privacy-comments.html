プライバシーポリシー

アプリ名：nekoshitsu-comments　対象チャンネル：ねこ質チャンネル（おっさん教育ラジオ）　連絡先：neko.shitsu@gmail.com　制定日：2026年11月21日

1. 本アプリがすること

本アプリは、運営する YouTube チャンネル（ねこ質チャンネル）に投稿されたコメントの対応と、番組制作の改善を目的としています。

  • コメントとその返信の一覧を取得する
  • 運営者の承認を得た文面で、コメントに返信する
  • 不適切なコメントを保留・非表示・スパム報告する（モデレーション）
  • チャンネルの分析データ（視聴維持率や動画ごとの統計など）を読み取り専用で取得し、番組制作の改善に役立てる

本アプリは、動画のアップロード・編集・削除を行いません。書き込みを行うのはコメントへの返信とモデレーションのみで、分析データの取得は読み取り専用です。

2. 利用する Google のサービスと権限

  • YouTube Data API v3 と YouTube Analytics API を使用します。
  • 要求する権限（スコープ）は https://www.googleapis.com/auth/youtube.force-ssl 、 https://www.googleapis.com/auth/youtube.readonly 、 https://www.googleapis.com/auth/yt-analytics.readonly です。
  • 実際に呼び出すのは、コメントに関するエンドポイント（commentThreads.list、comments.list、comments.insert、comments.setModerationStatus、comments.markAsSpam）と、統計・分析の読み取り専用エンドポイント（videos.list、channels.list、Analytics レポート取得）のみです。

3. 取得する情報

  • コメントの本文、投稿者名・チャンネル ID、投稿日時
  • 返信の文面（運営者が承認したもののみ送信します）
  • 分析データ（視聴維持率、再生回数・高評価数・コメント数などの集計値）
  • OAuth のアクセストークンおよびリフレッシュトークン（認証の維持に必要です）

上記以外のアカウント情報（パスワード、連絡先、他の Google サービスのデータなど）は取得しません。

4. 情報の利用と保管

  • 取得したコメントは、返信文案の作成とモデレーションの判断にのみ使います。分析データは番組制作の改善のための分析にのみ使います。
  • 第三者に販売・提供しません。広告配信や、第三者の分析サービスのために使うこともありません。
  • トークンは運営者の管理する環境にのみ保管し、第三者と共有しません。
  • 返信は、運営者が文面を確認・承認したものだけを送信します。

5. 情報の削除と権限の取り消し

  • Google アカウントの「サードパーティによるアクセス」設定から本アプリのアクセスを取り消すと、以降のアクセスはできなくなります。
  • 取り消しの申し出があれば、保管しているトークンを削除します。
