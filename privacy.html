プライバシーポリシー

対象：ねこ質チャンネル アップロード（以下「本ツール」）　制定日：2026年11月13日

1. 本ツールについて

本ツールは、ねこ質チャンネルの運営者が、自分の YouTube チャンネルに自分の動画をアップロードし、タイトル・説明文・公開日時・再生リストなどを設定するためだけに使う、個人用のツールです。本ツールは YouTube API Services を利用しています。

2. 利用する情報

本ツールは、運営者本人が Google の承認画面で許可した範囲で、運営者自身の YouTube チャンネルの情報（チャンネル、動画、再生リストの情報）にアクセスします。運営者以外の人の情報は、取得・保存・利用しません。

3. 情報の使い道

アクセスした情報は、運営者の動画のアップロードと、その動画の情報の設定にだけ使います。分析・広告・販売などには使いません。

4. 保存と共有

Google から受け取る承認の情報（アクセストークン・リフレッシュトークン）は、運営者のパソコンの中（macOS のキーチェーン）にだけ保存し、外部のサーバーには送りません。情報を第三者に提供・共有することはありません。

5. 承認の取り消し

本ツールへの承認は、Google アカウントのセキュリティ設定（https://myaccount.google.com/permissions）から、いつでも取り消せます。取り消すと、本ツールはチャンネルにアクセスできなくなります。保存している承認の情報も、運営者がいつでも削除できます。

6. YouTube と Google のポリシー

本ツールは YouTube API Services を利用しています。YouTube の利用規約（https://www.youtube.com/t/terms）と、Google のプライバシーポリシー（https://policies.google.com/privacy）もあわせてご確認ください。

Privacy Policy (English)

"Nekoshitsu Channel Upload" (the "Tool") is a private tool used only by the owner of the Nekoshitsu Channel to upload the owner's own videos to the owner's own YouTube channel and to set their titles, descriptions, publishing schedules and playlists. The Tool uses the YouTube API Services.

The Tool accesses only the owner's own YouTube channel data (channel, videos and playlists) within the scopes the owner authorized on Google's consent screen. It does not collect, store or use any data about other people. The data is used only to upload the owner's videos and set their metadata, and is never used for analytics, advertising or sale.

The authorization tokens received from Google are stored only on the owner's computer (macOS Keychain) and are never sent to any other server or shared with any third party. Access can be revoked at any time at https://myaccount.google.com/permissions.

Please also see the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy). Contact: neko.shitsu@gmail.com
